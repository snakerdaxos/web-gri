## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pantalla del dispositivo → entorno físico | Mostrar la contraseña en claro la expone a quien mire la pantalla |
| formulario → Firebase Auth | La confirmación de contraseña no debe alterar el payload enviado |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-06-01 | Information Disclosure | toggle de visibilidad | accept | Riesgo de shoulder-surfing inherente y aceptado: el estado por defecto es SIEMPRE oculto, la revelación es explícita por acción del usuario y no persiste entre pantallas ni entre sesiones |
| T-11-06-02 | Tampering | campo de confirmación | mitigate | La confirmación vive solo en la capa de UI; no se pasa a `RegisterController.submit` ni se almacena |
| T-11-06-03 | Information Disclosure | `autofillHints` en registro | mitigate | Se usa `AutofillHints.password` (no `newPassword` inconsistente) igual que el login, para que el gestor de contraseñas del sistema trate ambos campos igual |
</threat_model>
