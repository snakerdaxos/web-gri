Contexto de arranque que el runbook debe explicar:
- Emuladores: `cd scripts && node run_emulators.mjs --only auth,functions,firestore --project demo-gri -- <cmd>`,
  o `firebase emulators:start` para una sesión interactiva. Java lo resuelve el wrapper.
- Apps contra emuladores: `flutter run -d chrome --dart-define=USE_EMULATORS=true`.
- `BOOTSTRAP_EMAIL` debe estar en `functions/.env` ANTES de arrancar el emulador de Functions.
- `mobile_scanner` funciona en Chrome sobre localhost (contexto seguro); además existe la entrada
  manual del código para no depender de una cámara.
- ⚠️ El emulador **no valida índices compuestos**: pasar el runbook contra emuladores NO demuestra que
  los índices estén bien. Esa comprobación es del plan 11-16, contra el proyecto real.
