Patrón para el shell del cliente (sustituye al `ConstrainedBox(maxWidth: 480)` fijo de
`app_shell.dart:31-35`). El error a evitar es BORRAR el `ConstrainedBox`: eso estira la app a todo el
ancho del navegador y empeora el desorden. Se convierte la jaula en un techo con adaptación:
```dart
body: LayoutBuilder(
  builder: (context, c) {
    // < 480: móvil real → sin restricción (hoy también lo hace)
    // 480–840: web/tablet estrecho → columna centrada de 480 (comportamiento ACTUAL)
    // >= 840: tablet ancho / desktop → columna más generosa (720), no 480
    final maxW = c.maxWidth < GriBreakpoints.contenidoMax
        ? double.infinity
        : (c.maxWidth < 840 ? GriBreakpoints.contenidoMax : 720);
    return Center(child: ConstrainedBox(
      constraints: BoxConstraints(maxWidth: maxW), child: navigationShell));
  },
),
```
VERIFICADO: ninguno de los 175 tests actuales pumpea `AppShell` (los tests montan pantallas sueltas
dentro de `MaterialApp(home: ...)`), así que este cambio no puede romperlos — y por eso mismo NO
tiene ninguna red de seguridad hoy. El test de 3 anchos es obligatorio.

Breakpoints del panel: usar los ya nombrados en `GriBreakpoints` (750 y 1100, valores hoy vigentes
en `app_shell.dart:72` y `dashboard_screen.dart:37`). NO migrar a los 600/840/1200 de Material 3:
desplazaría el punto de colapso del sidebar y del grid, que es un cambio visual prohibido.

Overflows confirmados:
1. `app_cliente/lib/features/reservas/reserva_wizard_screen.dart:340-361` — `_ResumenRow` con `Text`
   de valor sin `Expanded`/ellipsis: overflow con cualquier nombre de restaurante largo.
2. `panel_admin/lib/features/reservas/reservas_screen.dart:181-227` — `_ReservaCard`: un único `Row`
   con hora (fontSize 20 bold) + `Expanded` + chip + DOS botones sin restringir. A ~650px de ancho de
   contenido (tablet de 768 menos sidebar y padding) desborda.

Ancho máximo de contenido en el panel: hoy `maxWidth` solo aparece en `login_screen.dart:83` y en un
diálogo. En un monitor de 1920 quedan ~1650px de contenido y las tarjetas se estiran enteras.
`ConstrainedBox(maxWidth: 1200)` centrado es el remedio estándar.
</interfaces>
