Backend endpoints (todos bajo http://localhost:8000, CORS incluye :5174):
```
POST /auth/register              {nombre, email, password} → UserRead                      201
POST /auth/login                 {email, password} → {access_token, refresh_token}          200
POST /auth/refresh               {refresh_token} → {access_token, refresh_token}            200
GET  /auth/me                    → UserRead                                                  200 (Bearer)
GET  /public/restaurantes        → [{id, nombre, tipo_cocina, descripcion, direccion, calificacion:null}]   200 (sin auth)
GET  /public/restaurantes/{id}   → {id, ..., calificacion:null, categorias:[{id, nombre, orden, productos:[{id, nombre, descripcion, precio:FLOAT, imagen_url, disponible}]}]}   200 (sin auth)
GET  /cliente/perfil             → UserRead                                                  200 (Bearer cliente)
PATCH /cliente/perfil            {nombre, password?} → UserRead                             200 (email ausente del body)
GET  /cliente/reservas           → [{id, restaurante_id, restaurante_nombre, mesa_id, mesa_numero, fecha, hora_inicio, num_personas, estado, created_at}]   200 (ordenadas fecha DESC)
POST /cliente/reservas           {restaurante_id, fecha, hora_inicio, num_personas} → ReservaRead   201 | 400 (past/non-:00) | 409 (capacidad/slot/raza)
POST /cliente/reservas/{id}/cancelar → ReservaRead                                          200 | 404 (ajena) | 400 (past) | 409 (ya cancelada)
```

<threat_model>
1. **Auth guard (redirect):** GoRouter redirect — sin AsyncData(User) no-null → /login; estando en /login logueado → /inicio. Igual que panel 04-02 (T-04-08).
2. **Token storage:** flutter_secure_storage 11.0 (Web = WebCrypto+LocalStorage, "obfuscado no cifrado" — aceptable sobre HTTPS, deuda Phase 9). Mismas keys gri_access/gri_refresh.
3. **Refresh storm (T-04-06):** QueuedInterceptor + Completer<String?> compartido — N 401s concurrentes → 1 solo /auth/refresh. Copiado del panel.
4. **COP formatting (Pitfall 3 cliente):** precio viene como float del backend; formatear con `intl NumberFormat.currency(locale:'es_CO', symbol:'\$', decimalDigits:0)` → "$ 32.000". NO concatenar strings manualmente.
5. **Slot validation cliente-side:** el wizard de hora DEBE restringir a :00 (dropdown de horas, no TimeOfDay libre) — coincide con la validación server (400 si non-:00).
6. **Existence hiding en UI:** errores 404 al cancelar reserva ajena (no debería pasar — solo ve las propias) y 409 al reservar slot tomado → mostrar mensaje user-friendly ("Ese horario acaba de ser reservado, elige otro").
7. **Mobile frame en web:** envolver en ConstrainedBox(maxWidth:480) + Center para que la preview Chrome se vea como móvil, no estirada.
</threat_model>
